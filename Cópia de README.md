# ONG Canto da Terra — site acadêmico

Site responsivo desenvolvido com HTML, CSS e JavaScript puro.

## Arquivos
- `index.html`: estrutura e conteúdo do site.
- `style.css`: identidade visual e responsividade.
- `javascript.js`: menu mobile, carrossel/favoritos, formulários e consulta de CEP pela API ViaCEP.

## Seções e funcionalidades
- História, missão, visão e valores da ONG.
- Serviços veterinários e animais para adoção.
- Formulário próprio para solicitar consulta veterinária, com seleção de data e horário preferido.
- Formulário separado para solicitação de castração.
- Formulário separado para demonstrar interesse em adoção.
- Formulário de contato e consulta de CEP pela API ViaCEP.
- Texto explicativo sobre a proposta de reservatórios/pontos de água e alimentação, sem implementar API, mapa interativo ou IoT.
- Identificação dos integrantes do grupo, sem funções atribuídas.

## Observação técnica
Os formulários validam os campos e exibem uma confirmação na interface, mas ainda não enviam os dados a um sistema externo. As datas e horários são preferências solicitadas pelo visitante; a disponibilidade real depende de confirmação da organização. A consulta de CEP usa a API pública ViaCEP. Imagens e fontes externas precisam de internet.

Abra `index.html` no navegador para visualizar.
